## Visual reconstruction
- Compact Student-brand header treatment, notification link and Student identity entry. Three compact Discovery tabs; unimplemented Center/Co-space remain disabled. No Student bottom navigation.
- Search and three quick controls immediately precede the map; large title replaced by an accessible heading.
- New local illustrated street/river/park texture, photo-dominant compact rating pins, distinct selected state. Schematic positions only; no provider, navigation, geolocation or distance claims.
- Rounded results sheet overlaps the map on mobile; compact live count and sorting; large portraits and a clear profile action.
- Card summary: photo, name, subjects, rating/reviews, primary area, stages, price, profile. Full model retained.
- Single-column filter sheet, Stage/System chips, location selectors, existing rating thresholds and price inputs, sticky actions.
- Desktop has a separate two-column layout with a sticky map.

## Functional engine preserved
Search normalization, filtering and sorting adapters are byte-identical to the technical base. Query serialization/parsing, 30 teacher records, IDs, routes, result order, filter count, reset, governorate-area dependency and returnTo remain unchanged. Pins prioritize existing portraits for presentation only; result ordering is unchanged. First teacher has no source photo and uses initials; no identity image was fabricated.

## Validation
Build/static export, TypeScript, Marketplace M1 and Unified U1 checks are run with the existing project scripts. Export audit wording follows the new schematic-map label without relaxing route/card/identity assertions.
Browser QA and rendered mobile side-by-side comparison are unverified: the required managed control-browser capability is unavailable. Do not treat this package as visually approved.
