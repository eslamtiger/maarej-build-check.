# V1.11: Maarej Unified design system

- One palette for the whole site: indigo brand (#4B3FD6), ink (#16133D), amber accent, violet-tinted neutrals. Legacy token names kept, so student and marketplace screens both pick it up.
- Fonts: Alexandria for headings, IBM Plex Sans Arabic for body text (one loaded pair instead of Alexandria + unloaded Noto).
- Removed the old teal student palette and the separate purple/blue accents in teacher search; folded into the brand color.
- One public header and footer for home, teachers, centers, spaces and profiles.
- Student header: "البحث عن السناتر — قريبًا" replaced with a working link to centers and spaces.
- Home: light editorial hero ("ابحث. قارن. اختار."), tabbed search, subjects strip, dark 3-step section; removed eyebrow labels.
- Search: horizontal result cards beside the map on desktop.
- Old changelogs and QA notes moved to docs/archive.
- Rules applied from Impeccable craft floor (no eyebrow labels, no gradient text, no emoji icons, min 12px text, visible focus, themed selection).
